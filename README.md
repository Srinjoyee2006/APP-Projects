# 🌸 APP Projects

This repository contains simple Java applications built using **Java Swing** and **Object-Oriented Programming principles**.  
Each project focuses on core Java concepts like GUI development, event handling, and basic logic implementation.

## 📚 Projects Included

### 🧮 Calculator App
A GUI-based calculator that performs basic arithmetic operations such as addition, subtraction, multiplication, and division using **Java Swing**.

### 🧾 Student Registration Form
A form-based Swing application that allows users to enter student details, validate inputs, and store them in a **MySQL database** using **JDBC**.
